# Дизайн инструмента очистки закладок Chrome — NoDebris

## Обзор

Инструмент для наведения порядка в закладках Google Chrome: поиск дубликатов, проверка битых ссылок и редиректов, авто-категоризация, упрощение структуры папок.

Форма: гибрид — CLI-режим для быстрого анализа + веб-интерфейс для интерактивной работы.

## Архитектура

### Подход B: CLI + Serve

Один бинарник с двумя режимами:
- `bookmark-cleaner analyze <file>` — CLI-отчёт в консоль
- `bookmark-cleaner serve` — веб-сервер на `localhost:8080`

### Технологический стек

- **Бэкенд:** Go (net/http, html/template)
- **Фронтенд:** HTMX + PicoCSS
- **Проверка ссылок:** стандартный net/http, HEAD-запросы с fallback на GET

## Модель данных

```go
type Bookmark struct {
    ID                 int
    Title              string
    URL                string
    Domain             string    // извлекается при парсинге
    FolderPath         string    // путь к папке, например "Видео/youtube/SRE"
    DateAdded          time.Time
    StatusCode         int       // 0 = не проверено
    RedirectURL        string
    IsDuplicate        bool
    IsBroken           bool
    SuggestedCategory  string
}
```

## Потоки обработки

### 1. Поиск дубликатов
Группировка по нормализованному URL (без trailing slash, без fragment). Пользователь выбирает, какой экземпляр оставить в каждой группе.

### 2. Проверка ссылок
Ручной запуск по кнопке. HEAD-запросы (fallback на GET) параллельно, concurrency 10-20. HTMX polling для обновления прогресса.

### 3. Авто-категоризация
Правила на основе домена:
- `github.com` → «Разработка/GitHub»
- `habr.com`, `medium.com` → «Статьи»
- `youtube.com` → «Видео»
- и т.д. Список правил — JSON-конфиг, расширяемый пользователем.

### 4. Упрощение структуры
Анализ дерева папок: папки с 1-2 закладками (предложить слить), глубокая вложенность (>4 уровней), пустые папки.

## UI и экраны

### 1. Загрузка (`/`)
Drag-and-drop HTML-файла или ввод пути к профилю Chrome.

### 2. Все закладки (`/bookmarks`)
Таблица с фильтрами (по папке, статусу), поиском, массовыми действиями, кнопками анализа и экспорта.

### 3. Дубликаты (`/duplicates`)
Группы дубликатов с выбором, какой оставить.

### 4. Проверка ссылок
Прогресс-бар с HTMX polling, цветовая подсветка результатов.

### 5. Структура папок (`/structure`)
Дерево папок с проблемными зонами и рекомендациями.

### 6. Экспорт
Генерация HTML-файла в формате Netscape Bookmark File Format для импорта в Chrome.

## Источники данных

- HTML-экспорт Chrome (Bookmark Manager → Export bookmarks)
- Прямое чтение файла `Bookmarks` (JSON) из профиля Chrome

## Визуальный стиль: «Тихий административный дашборд»

Вдохновение: Stripe Dashboard, Linear (светлая тема). Никаких декоративных элементов, градиентов, иллюстраций. Только типографика, границы и цвет для статусов и действий.

### Палитра (светлая тема)

| Роль               | Цвет      | Где использовать                               |
|--------------------|-----------|------------------------------------------------|
| Фон страницы       | `#FAFBFC` | Общий фон (Cloud White)                        |
| Поверхность        | `#FFFFFF` | Карточки, панели, таблицы (Snow Surface)       |
| Границы            | `#E4E4E7` | Линии таблиц, разделители (Mist Border)        |
| Основной текст     | `#18181B` | Заголовки, URL (Ink Black)                     |
| Вторичный текст    | `#71717A` | Подписи, метаданные, placeholder (Stone Text)  |
| Акцент             | `#0172AD` | Кнопки, ссылки (Pico Default Primary)          |

### Цвета статусов

| Статус         | Цвет      | Применение                 |
|----------------|-----------|----------------------------|
| OK (200)       | `#10B981` | Бейдж «Живая»              |
| Ошибка (404)   | `#EF4444` | Бейдж «Битая»              |
| Редирект (3xx) | `#F59E0B` | Бейдж «Редирект»           |
| Дубликат       | `#A1A1AA` | Пометка в таблице          |

### Практики по экранам

- **Таблица (`/bookmarks`):** только горизонтальные линии `#E4E4E7`, заголовки полужирные, меньшего размера. Чекбоксы — стандартные Pico.
- **Дубликаты (`/duplicates`):** карточки `<article>` вместо таблицы. Внутри — радио-кнопки. Кнопка «Оставить выбранные» — Primary.
- **Структура (`/structure`):** вложенные `<ul>` для дерева. Рекомендации — карточка с фоном `#F4F4F5` и кнопкой «Применить».
- **Прогресс:** нативный `<progress>` Pico. Расположен над таблицей, не сдвигает контент.
- **Плотность:** переопределить переменные Pico для компактной таблицы:
  ```css
  :root { --pico-spacing: 0.5rem; }
  table td, table th { padding: 0.4rem 0.6rem; }
  ```

## Состояние

Сервер **stateless** — закладки и результаты анализа хранятся в памяти сессии (в рамках одного запуска `serve`).
