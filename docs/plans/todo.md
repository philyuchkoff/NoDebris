# План задач — NoDebris

## Высокий приоритет

- [ ] Написать парсер HTML-экспорта Chrome (Netscape Bookmark File Format)
- [ ] Написать парсер Chrome Bookmarks JSON из профиля
- [ ] Создать единую модель Bookmark и нормализацию URL
- [ ] Реализовать поиск дубликатов (группировка по нормализованному URL)
- [ ] Реализовать HTTP-проверку ссылок (HEAD с fallback на GET, concurrency control)
- [ ] Создать веб-сервер на Go (net/http) с базовым роутингом
- [ ] Сверстать базовый layout (PicoCSS + HTMX)
- [ ] Экран загрузки (drag-and-drop HTML / путь к профилю)
- [ ] Экран «Все закладки» — таблица с фильтрами, поиском, массовыми действиями
- [ ] Экран «Дубликаты» — карточки групп, выбор и удаление
- [ ] Инлайн-блок проверки ссылок с прогресс-баром (HTMX polling)
- [ ] Экран «Структура папок» — дерево, рекомендации
- [ ] Экспорт в HTML (Netscape Bookmark File Format) для импорта в Chrome
- [ ] CLI-режим: консольный отчёт (`analyze`)

## Средний приоритет

- [ ] Авто-категоризация по домену (JSON-конфиг правил)
